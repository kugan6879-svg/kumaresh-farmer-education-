# Farmer Education Website

A mobile-friendly educational website concept for farmers.

## Features
- Farming topics: soil health, water saving, crop care, weather awareness, sustainable farming, and government schemes
- Short lessons in English and Tamil
- Responsive layout for mobile and desktop
- Alignment with SDG 2, SDG 4, and SDG 12

## How to use
Open `index.html` in a web browser. No installation is needed.

## Important
This is an educational prototype. It does not provide live weather data or verify current government schemes. Confirm important agricultural decisions with trusted local experts and official sources.
